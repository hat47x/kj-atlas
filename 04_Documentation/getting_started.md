# 最初の意味ある配置を作る

対象読者: kj-atlas を初めて起動し、基本的な価値を安全に体験したい利用者・評価担当者。

目的: AIを使わず、秘密情報を含まない標準サンプルから、カード3件、まとまり1件、未決1件を確認し、保存・再読込・共有前確認まで進みます。

範囲外: AI提案、自動分類、実データの取り込み、ファイルの書き出し、他者への共有、クラウド同期、全機能の動作確認。

完了状態: 「何をまとめたか」「何をまだ決めていないか」「外部共有を実行していないこと」を画面上で説明できます。

所要時間の目安は10分です。機能全体を検査したい場合は、この教程ではなく[受け入れ確認](acceptance_check.md)を使ってください。

## 始める前の安全確認

1. [導入手順](installation.md)に従ってアプリを起動し、ブラウザで開きます。
2. LLM provider は既定の `KJ_ATLAS_LLM_PROVIDER=none` のままにします。
3. 「作業を開始」パネルの安全状態が `セーフモード: ON` であることを確認します。OFFならここで止め、[設定ガイド](configuration.md)と[セキュリティ](security.md)を確認してください。
4. この教程では標準サンプルだけを使います。氏名、顧客情報、API key、token、passwordなどを入力しないでください。

![SafeModeを確認できる作業開始パネル](assets/screenshots/start-document-entry.png)

## 9つの手順

| 手順 | 目的と操作 | 期待する状態 | 取消・安全な停止 |
| --- | --- | --- | --- |
| 1 | 「作業を開始」で `サンプルを開く` を選びます。 | 開始パネルが閉じ、キャンバスが表示されます。 | 開けない場合は入力を続けず、[診断と障害調査](diagnostics.md)へ進みます。 |
| 2 | `ユーザー課題を集める`、`観察メモをカード化する`、`似ている内容を近くに置く` の3カードが見えることを確認します。 | 秘密情報を含まない固定題材が3件あります。 | 文言や件数が違う場合は、実データを追加せず教程を止めます。 |
| 3 | `ユーザー課題を集める` を選び、Shiftを押しながら `観察メモをカード化する` を選びます。 | 2件が選択状態になり、ヘッダーの `島を作成` が使えます。 | Escまたはキャンバスの空白を選び、選択を解除できます。 |
| 4 | ヘッダーの `島を作成` を選びます。 | 「選択したカード 2 件から島を作成しました」と表示され、2カードを含むまとまりができます。 | Ctrl+Z（macOSはCmd+Z）で元に戻せます。戻した場合はCtrl+YまたはCmd+Shift+Zでやり直します。 |
| 5 | Escで島の選択を解除してから、まとまりに入れなかった `似ている内容を近くに置く` を選び、右側の `保留状態` を `未決` にします。 | 右側の「現在の選択」が「カードを選択中」になり、まとめた2件とは別に「まだ決めていない」カードが1件残ります。 | 右側が「島を選択中」のままならEscを押してカードを選び直します。`保留状態`を`通常`に戻すか、Ctrl/Cmd+Zでも取り消せます。 |
| 6 | 画面を読み返します。島に2カード、島の外に`未決`の1カードがあることを確認します。 | 「まとめた内容」と「未確定の内容」を区別して説明できます。 | 意図と違う場合は保存せず、手順3〜5をやり直します。 |
| 7 | ヘッダーの `保存` を選び、`保存しました` を確認します。 | 変更がbackendへ保存されます。 | `ドキュメントを保存できませんでした` と出た場合は再読込せず、後述の「保存できない場合」へ進みます。 |
| 8 | ブラウザを再読込し、`ドキュメントを読み込みました` を待ちます。「作業を開始」パネルが表示されている場合は右上の×（`開始パネルを閉じる`）で閉じ、島と`未決`が残っていることを確認します。`サンプルを開く`は選び直しません。 | 保存した配置と状態を再現できます。 | 読込中は操作しません。内容が消えた場合は新しい編集を加えず、[診断と障害調査](diagnostics.md)へ進みます。 |
| 9 | `共有と再現` を開き、`共有前チェック`でSafeMode、公開範囲、未レビュー情報、出力形式を読みます。この教程では書き出しや共有を実行せず、Escで閉じます。 | SafeModeがONで、未レビューの内容が共有時に制限されることを確認できます。外部共有はまだ0件です。 | 内容や共有範囲を説明できなければ実行ボタンを選ばず、[データ取り扱い](data_handling.md)を確認します。 |

## 完了チェック

- [ ] カードが3件ある。
- [ ] 2カードを含む島が1件ある。
- [ ] 島に入れず、`未決`として残したカードが1件ある。
- [ ] 保存後の再読込でも同じ状態が見える。
- [ ] `共有前チェック`でSafeModeと未レビュー情報の扱いを確認した。
- [ ] ファイルの書き出し、他者への共有、AI提案を実行していない。

ここまでできれば、kj-atlasの最初の価値である「情報をまとめながら、決めきれない内容を消さずに残す」を体験できています。次は、日常の開始・保存・終了方法を[運用手順](operations.md)で確認するか、画面全体を[現行UIカタログ](ui_catalog.md)で確認してください。

## 保存できない場合

保存に失敗しても、画面を再読込・終了するまでは内容が画面上に残っている場合があります。

1. 直ちに再読込せず、表示されたエラーを秘密情報なしで記録します。
2. `共有と再現`からDocumentV2 JSONを書き出せる場合は、共有せずローカルの安全な場所へ退避します。書き出す前に[データ取り扱い](data_handling.md)のチェック項目を確認します。
3. [診断と障害調査](diagnostics.md)の「画面は開くが保存できない」に従ってAPIとDBを確認します。
4. 解決しない場合は[サポート](../SUPPORT.md)へ進みます。ログや画像にはAPI key、token、password、実データを含めないでください。
