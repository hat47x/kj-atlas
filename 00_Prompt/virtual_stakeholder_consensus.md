# 判断整理の補助

> Status: On-demand. 個人OSSの通常タスクでは使用しない。

仮想的な複数役職を会議参加者として再現する方式は、現在の単独開発では意思決定者を増やさず、記録量だけを増やすため既定運用から外す。

## 使用する場合

次の条件をすべて満たす場合に限り、判断材料の整理に使う。

- 複数の合理的な選択肢が残る。
- 変更が長期的、横断的、破壊的、または安全境界に影響する。
- 上位文書と事実確認だけでは一案に決められない。

## 最小出力

1. 決めること
2. 確認できた事実
3. 選択肢と主な利点・欠点
4. 推奨案と理由
5. 未決事項または人間確認が必要な点

可逆で安全境界を変えない通常判断は、Maintainerが対象issueで決定する。仮想役職、RACI、期限付き承認キュー、12項目の会議録は作成しない。
