# AIエージェント引き継ぎ補足

> Status: On-demand. 通常の作業開始時には読まない。

日常の作業規則は `AGENTS.md` に集約した。この文書は、長時間タスクを別のAIまたは別セッションへ引き継ぐ必要がある場合だけ使用する。

## 引き継ぐ情報

- 目的と変更対象
- 完了済みの作業
- 未完了の受入条件
- 現在のブロッカー
- 次に実行するコマンドまたは編集対象
- 実行済みテストと未実施理由
- 作業ブランチと未コミット差分の有無

## 引き継がない情報

- リポジトリ全体の説明
- 全ADR・全issueの要約
- 完了済みrerunやStreamログ
- 対象外機能の設計本文
- Git履歴から確認できる逐次作業ログ

安全境界、最小読取、作業手順は引き継ぎ先でも `AGENTS.md` を正本とする。
