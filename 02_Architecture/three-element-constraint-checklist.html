三要素整合チェックリスト

区分: 設計ツール / 更新: 2026-08-08 / 正本: ADR-0067
用途: 新規ADR起票時・画面/API新規設計時・データ境界変更時に、三要素の整合を確認する。 全項目に合格するまで設計判断を着工しない。

使い方: 設計判断ごとに、下表のチェック項目を3次元から実行する。 1つでも ✗ があれば、該当次元の設計を補正し、3次元すべてが ✓ になるまで反復する。 判断不能（△）の項目は、判断に必要な情報を収集してから再チェックする。

1. 基本チェック（全設計判断共通）

#次元チェック項目判定基準
B1業務この設計判断がないと、どの利用者journeyが完遂できないか明確に述べられている「便利だから」「あったほうがいい」ではなく、欠如時の具体的な障害が特定できる
B2業務既存の「侵してはならない核」と衝突しない（SafeMode・proposal-only・反スコアリング・キャンバス主従・保留の健全性）ui_design_handoff.md の6核すべてとの整合を確認
B3業務画面を純増させず、既存画面の置換・包含・モード分離で収まっているADR-0043 複雑性予算を参照。新規操作を既定表示へ追加していない
B4業務利用者種別（Standard user / Tenant Admin / Platform operator）とcapabilityが明確誰が操作できるか、capability不足時の挙動が定義されている
D1データこの設計判断が扱うデータの正本と保存範囲（サーバー/文書内/端末のみ/環境変数）が明確正本が不明なデータをUIが表示・編集しようとしていない
D2データ表示する情報が「識別メタデータ」か「知的成果物本体」か区別され、管理面で後者を表示していないadmin-surface-metadata-display-correction.html の境界定義を参照
D3データデータ境界クラス（L1運用〜L0計画）と実装状態が一致しているdata_model_operations_overview.html のCRUD表と照合
D4データSafeMode ON時に表示・送信される情報がSafeModeの制約を満たす（未レビュー本文の非表示等）THREAT_MODEL.md のSafeMode境界と照合
F1機能必要なAPI endpointが api.md で契約済み、または本設計判断の一部として契約を定義している未契約APIを前提とした画面設計を行っていない
F2機能画面の全状態（Loading / Empty / Ready / Error / Blocked / Read-only）が定義されている異常状態がEmptyやReadyと混同されていない
F3機能capability不足時の表示が定義され、権限なしのEmptyへ偽装していないblocked stateがEmpty/read-only/Network errorと区別されている
F4機能不可逆操作に確認が含まれ、取消方法が提供されている削除・失効・公開範囲変更等の確認UIがある

2. 次元間クロスチェック（牽制検証）

#牽制チェック項目実例（管理面タイトル表示補正）
X1業務→データ業務上必要な表示項目が、データの非表示原則を侵していないか✓ タイトルは識別メタデータのため表示可。カード本文は非表示（侵さず）
X2業務→機能業務要求が未契約APIを暗黙に前提としていないか✓ GET /docs はタイトルを返す。新規API不要
X3データ→業務データの保存範囲が、業務上の編集操作と矛盾していないか✓ タイトルはDocument.titleとして保存され、文書保存で永続化される
X4データ→機能データ境界クラスが、APIのCRUDサポートレベルと一致しているか✓ タイトルはL1 Supported。PUT /docs/{id} で保存可能
X5機能→業務APIの状態遷移が、業務シナリオの全経路をカバーしているか✓ 保存失敗（409競合）→再読込→再編集 の経路が定義済み
X6機能→データAPIの有無がデータ境界クラスを歪めていないか（APIがあるからL1運用可能と誤認させない）✓ タイトルはDocument全体の一部であり、タイトル単独のAPIは不要

3. KJ法固有チェック

#次元チェック項目判定基準
K1業務AI提案は候補生成に留まり、人間の明示操作なしに文書へ反映されないproposal-only。一括Adoptを新設していない
K2業務保留・違和感の保持・表現を妨げない。確定を促すUI（「解決」ボタン等）を置かないamberが保留・違和感以外に使われていない
K3データカードのka（声・価値）フィールドがSafeMode時に適切に制御される未レビューkaはAIへ送信しない
K4データEvidenceLink・出典参照がSafeMode・共有時に適切に制御される未レビュー出典は共有出力から除外
K5機能AI提案のタスク名が操作別モデルレベル定義に含まれているAGENTS.md §1.2 の表にタスクが登録済み
