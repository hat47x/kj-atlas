# Cognitive Dogfood Experimenter Notes: 文化体系候補の選別

- Status: Experimenter-only / not arm input
- Date: 2026-08-29
- Method snapshot: `hat47x/cultural-substrate-weaving@3988e12e5f7f316f377d3391e9486c8467a111d5`
- Related: Case 000 audit / Case 001

> この文書はCase 001のA〜Dへ渡さない。実験設計者が、どの体系候補が有効/不適切かを事前に記録し、結果を見てから体系選択理由を書き換えることを防ぐためのメモである。

## 1. 対象

対象は「KJ Atlasの存在目的と一次利用仕事」そのものに加え、その問いをKJ Atlas＋生成AIで考える認知系である。

観察層を混ぜない。

1. **Product layer**: KJ Atlasが利用者に何を提供するか。
2. **Cognitive-work layer**: 人間・AI・キャンバス・根拠がどう相互作用するか。
3. **Development-feedback layer**: dogfood→issue/ADR/実装→次dogfoodがどう循環するか。

文化体系はこの3層のどこへ使うかを宣言する。

## 2. 対象が既に内在化している体系

KJ Atlasの `00_Prompt/kj_technique.md` は、KJ法に加え、荘子の「渾沌」の寓話を明示的な認識論として取り込んでいる。

したがって、荘子的な「分割しすぎない」「全体を殺さない」観点を文化体系による新規増分として再投入しない。

### Framework-independence監査候補

外部体系による増分を主張する前に、次を確認する必要があるかもしれない。

> その体系または同型の原理が、対象の自己記述・設計原則・基準線へ既に組み込まれていないか。

既に組み込まれている場合、体系適用後に同じ方向の所見が増えても「外部体系が新しい位置を示した」とは限らず、対象の自己理解を増幅しただけかもしれない。

現行スキルの基準線/増分規則で吸収できる可能性もあるため、現時点ではskill defectと認定しない。Case 001以降で再現する場合だけ方法規則候補へ上げる。

## 3. 候補A: 五行 — 異種の関係生成器として限定採用候補

### 用途

- Development-feedback layer
- Cognitive-work layer
- **分類には使わない。**
- 五相へKJ Atlasの機能・主体を割り当てない。

対象の構造単位と五行の位置は同種ではなく、機械的な割当規約もない。このため欠落判定や「KJ Atlasには火が足りない」等の言明は禁止する。

一方、`system-selection.md` が異種体系に許す用途として、**関係を表す動詞**を得る目的で、生成/抑制の二種類の関係を使う。

### 生成する問い

#### G1 自己強化するものは何か

- dogfoodが新しいissue/ADR/機能を生み、それがさらにdogfood能力を高める循環はあるか。
- AIが設計文書を増やし、増えた設計文書がさらにAIの設計規則を増やす循環はあるか。
- 安全/統治規則が追加され、規則の存在がさらに監査・規則追加を必要とする循環はあるか。

これらは良い/悪いを先に決めず、対象側で実在するフィードバックとして確認する。

#### G2 過剰を抑えるものは何か

候補:

- human final authority
- proposal-only
- provenance grounding
- dissent/residual preservation
- ADR-0047のADR saturation制御
- dogfoodでの過大申告訂正
- stop condition

問い:

- 各生成ループに対して、実際に働く抑制ループがあるか。
- 抑制は過剰だけを止めるか、必要な探索/利用可能性まで止めていないか。

#### G3 抑制そのものが過剰化していないか

Case 0 R1には「設計原理が強固すぎて実務の識別能力を奪う」という問題提起がある。

したがって、制御機構を多いほど良いとは扱わない。

問い:

- fail-closed、安全境界、ADR/issue契約、AI proposal-onlyが、価値を守る制御として働く領域はどこか。
- 同じ制御が、初回利用、探索、変更可能性、外部参加を阻害する領域はどこか。

#### G4 系の外から何が入るか

内部dogfoodはKJ Atlas自身の資料をKJ Atlasで分析する。

ここから次の仮説を立てる。

> 自己dogfood→設計変更→自己dogfoodの循環だけが強くなると、内部整合性は上がっても、社会に実在する利用仕事から離れる自己参照的最適化が起こり得る。

外部から入る候補:

- 第三者が自分の題材を持ち込んだ実利用観察
- 異なる実践文化
- 競合/代替手段との比較
- 実装後の利用離脱/摩擦
- 対象分野の専門知識

この問いは `VALUE-REALNESS-01` を単なる市場検証ではなく、**認識系を外部現実へ接地する負帰還/外生入力**として再解釈する可能性がある。

#### G5 外部入力を内部体系が無害化していないか

外部利用者の違和感が、既存ADR/価値原則/KJ語彙へすぐ翻訳されると、外部入力を受け取ったように見えて既存体系の自己確認になる。

問い:

- 外部観察を既存の価値分類へ入れる前に生カードとして保持できるか。
- 「この製品を使わない」という判断を改善要求へ自動変換せず、そのまま保持できるか。

### 不採用条件

次なら五行由来の増分を認めない。

- 上記の問いが通常のsystems thinking / feedback-loop分析だけで同じ粒度で出る。
- 生成/抑制という語を使っただけで新しい対象側所見がない。
- 五行の要素名・配当を持ち込まなければ成立しない結論しか出ない。

substitutionとして通常のcausal-loop/feedback分析を当て、同じ所見が出る場合は「五行固有」ではなく対象/一般システム分析由来とする。

## 4. 候補B: 陰陽 — 主体系としては保留/低優先

### 期待できる対比

- 速度 / 熟慮
- 自動化 / 人間主体
- 収束 / 残差保持
- 利便性 / forcing friction
- 内部整合 / 外部適応

### 保留理由

これらの対立は既にKJ Atlasの資料やCOGNITIVE-EVALで明示されており、二項対立を再提示するだけでは新規増分が小さい可能性が高い。

また、何でも二極へ読めるため不採用条件が弱くなりやすい。

Case 001では主体系として事前採用しない。別ケースで明確な二相間の相互変換が対象側にある場合に再検討する。

## 5. 候補C: 易の変化モデル — 現時点では不採用

### 魅力

状態遷移、変化、未到達状態、戻れない状態を豊かに探索できる可能性がある。

### 不採用理由

KJ Atlasのproduct/cognitive stateを64卦/六爻へ割り当てる対象独立の規約が現時点でない。

分析者が「似ている卦」を選ぶ方式では解釈語の層に落ち、transition gridとして欠落/未到達を論じる根拠にならない。

現時点では、体系の豊かさがframework captureを起こすリスクが増分を上回ると判断する。

## 6. 候補D: 五倫 — 不採用

人間、AI、maintainer、利用者、source owner等の非対称な責任関係を考えるきっかけにはなり得る。

しかし、五倫は歴史的・社会的役割関係を単位とし、KJ Atlasのactor/authority関係とは分類原理が異なる。特定の伝統的役割を現代の人間-AI統治へ写すこと自体が強い規約依存になる。

関係一般の問いは、責任分界/権限モデル等の領域手法で扱う方が直接的であるため不採用。

## 7. 候補E: 序破急 — Case 001では不採用、別テーマへ保留

初回利用→探索深化→決定/共有の時間設計や、認知摩擦の配置を考える時間モデル候補にはなり得る。

しかしCase 001の中心問いは「存在目的/一次利用仕事」であり、利用時系列が中心ではない。現在の問いへ無理に適用せず、onboarding/long-session UX等のケースで再検討する。

## 8. 現時点の文化体系由来の生カード候補

以下は結論ではなく、後で対象へ戻して検証する問い/仮説カードである。

1. 内部dogfoodが内部dogfood能力を高める自己強化循環がある。
2. 強い内部自己改善循環は、外部現実からの入力が弱いと自己参照的最適化へ進む可能性がある。
3. 第三者価値検証は市場適合の確認だけでなく、自己参照的認知系を外部現実へ接地する役割を持ち得る。
4. KJ Atlasには生成を促す仕組みだけでなく、AI・設計・探索の過剰を抑える多くの制御機構が既にある。
5. 制御機構は価値を守る一方、強すぎると探索・初回利用・変更可能性を損なうため、制御そのものにも適正範囲がある。
6. 外部の違和感を既存ADR/KJ/価値語彙へすぐ翻訳すると、外部入力を受けたように見えて自己確認へ吸収する危険がある。
7. 「使わない」という第三者判断を改善要求へ変換せず、そのまま反証として保存できることが外部接地に必要である。

## 9. 対象へ戻す検証

上記カードを採用する前に、次を行う。

- repository上で自己dogfood→変更→次dogfoodの循環が実在する証拠を確認する。
- 内部dogfoodの増加と第三者実利用証拠の量を別々に確認する。
- 既存の一般的systems-thinkingだけでも同じ問いが出るか substitutionする。
- 第三者実利用が入ったとき、内部価値仮説が実際に変更/棄却された事例を将来追跡する。
- 「制御が強すぎる」という主張は具体的な利用摩擦なしに事実認定しない。

## 10. Skill improvement候補（未採用）

### S-CAND-01 Framework independence / target-incorporation check

仮説:

> 外部体系による増分を測る際、対象がその体系または同型原理を既に自己記述へ取り込んでいる場合、体系適用後の所見を独立した増分として数えないための検査が必要かもしれない。

現時点では `scope-and-facts.md` の実基準線と増分判定で十分吸収できる可能性がある。

**採用条件:** 複数ケースで、対象に既に内在する体系を使ったarmが見かけ上の増分を過大計上し、現行のbaseline/removal/substitutionだけでは防げないことが再現する。

採用条件を満たすまでは `cultural-substrate-weaving` 正本を変更しない。
