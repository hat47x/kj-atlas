# ADR-0010: 価値原則の明示（ADR-0001分割）

- Status: Accepted
- Date: 2026-02-24
- Deciders: Project Maintainers
- Scope: `01_Plans/`
- Derived-from: `01_Plans/adr/ADR-0001-value-to-requirements.md`

## Context

`ADR-0001` は価値観・要求・バックログ・チケット化規則を単一文書で保持しており、参照単位が粗い。

## Decision

価値原則（保留尊重、反スコアリング、人間レビュー中心、safeMode既定ON）を本ADRに独立させる。
要求や実装計画は別ADRへ分離する。

## Three-Element Verification（ADR-0067 遡及適用）

| 次元 | このADRでの主張 | 他次元への制約 |
|------|----------------|---------------|
| **業務設計** | 価値原則（保留尊重・反スコアリング・人間レビュー中心・safeMode既定ON）を独立ADRとして固定し、価値判断の参照先を短くする。要求や実装計画は別ADRへ分離 | 機能: 下流文書は本ADRを前提として要求や受入条件を記述する。データ: 価値原則は実装都合で緩和しない |
| **データ設計** | ADR-0001の「1. 価値観（原則）」を本ADRへ独立させる。P-01〜P-09の価値原則を一箇所で保持 | 業務: 価値判断の参照先を短く固定しスコープドリフトを防ぐ。機能: 要求マッピング（ADR-0011）と計画起票（ADR-0012）へ分離接続 |
| **機能設計** | 価値原則を参照しやすい単位に分割し、ADR-0011/0012との関係を明示する | 業務: 要求マッピングとチケット化は価値原則に整合させる。データ: 反スコアリング・人間レビュー中心・safeMode既定ONを全設計判断の前提とする |

## Consequences

- 価値判断の参照先を短く固定できる。
- 下流文書は本ADRを前提として要求や受入条件を記述する。
